Omega Blocks is a WordPress plugin that provides a collection of useful custom blocks for the Gutenberg editor, including shape dividers and dynamic buttons.

== Description ==

Omega Blocks provides several custom blocks to enhance your content:

* **Curvy**: Add beautiful shape dividers to your page content with customizable top and bottom curves.
* **Clicky Group**: A container for dynamic buttons to manage layout and alignment.
* **Clicky Button**: Call-to-action buttons that dynamically link to your site's posts or pages.

== Installation ==

1. Upload the plugin files to the `/wp-content/plugins/omega` directory.
2. Activate the plugin through the 'Plugins' screen in WordPress.
